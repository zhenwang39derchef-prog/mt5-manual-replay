# 已知限制

1. 已完成实机验收的环境为 Windows x64、Exness 桌面版 MT5、XAUUSDm。其他经纪商、其他品种及 MT5 构建版本尚未逐一验收。
2. 默认 MT5 安装路径和数据目录来自开发环境。首次使用必须在“安装位置”手动选择自己的目录；两个目录的 `origin.txt` 关系会被核对。
3. 品种默认 XAUUSDm；其他经纪商应手动填写实际名称。默认价格反比手数为黄金练习设置；其他品种请在“手数匹配”中核对并选择合适的手动手数方式。
4. 当前为 Windows 桌面入口与 MQL5 EA 配合使用的发行包。Mac、Linux、网页和移动版未验收。
5. 选择“启动本次练习”会请求所选安装中已打开的 MT5 正常退出。请先保存其余工作。工具拒绝强制结束无法正常退出的 MT5。
6. 多周期观察窗最多封存每周期最近480根已知K线；可用资料不足时显示不可用或仅已收盘数据。
7. 多周期窗口只读，主交易周期在启动前选择。历史K线、点差和成交条件来自本场策略测试器。
8. 价格计划最多两位小数；MT5 订单和原生报价继续使用品种自身精度。
9. 程序需要在可写目录运行，保持 `assets` 与程序同目录。安装包不含 MT5、账户或历史行情。
10. 本仓库的便携测试覆盖部分模型与界面逻辑，不能替代不同安装环境的真实 MT5 回放验收。
