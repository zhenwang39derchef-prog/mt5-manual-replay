# v1.2.6 验证范围

首次公开包沿用已验收的桌面 EXE 与 EA 1.45 原生文件。生产源码与自用版逐项校验一致。

原有验证共891项：桌面基线621，多周期模型与隔离59，渲染与布局组件59，MT5原生单元113，真实测试器数据和收工退出39。

正式版桌面操作也已经实际验证：

- 打开观察窗，在M5 / M15 / H1 / H4之间切换。
- 缩放、浏览历史、回到当前、显隐EMA；观察过程中回放与交易状态保持一致。
- 左右对照布局，关闭观察窗后恢复原MT5窗口位置和大小。
- 重开保留周期、显示数量与EMA选择。
- 确认收工后显示成功回执，三题复盘依次显示。
- 完成复盘正常退出本场程序，原始现场与最终结果分别保存。
- MT5退出后，从入口重新找回档案并打开、切换离线图表。

上述真实场景在Windows x64 / Exness MT5 / XAUUSDm上完成。它不代表所有经纪商、品种、MT5构建和缩放组合都已验收。

仓库附带49项档案检查与59项多周期模型/控件检查，执行 `Test.ps1` 可重跑。它们使用合成数据；不附维护者的本机日志、真实历史行情或个人交易资料。

更换经纪商或MT5构建后，建议在一个练习场次验证：启动和计划 → 测试下单、挂单和拖线 → 暂停 → 多周期切换、关闭与重开 → 收工 → 档案找回。记录MT5构建号与具体失败步骤。
